THE DAILY GRIND CAFE — HTML + CSS WEBSITE
==========================================

FILES
-----
index.html — Complete webpage structure and content.
style.css  — All visual styling and responsive layouts.

HOW TO OPEN
-----------
1. Extract the ZIP file.
2. Open the Cafe_HTML_CSS_Website folder.
3. Double-click index.html in a modern browser.
4. Internet access is recommended for Google Fonts and Unsplash photos.

INCLUDED SECTIONS
-----------------
- Welcome / hero section
- Menu with categories and sample prices
- Special items with photos
- Customer review cards
- Opening hours
- Location and contact information
- Footer navigation

NOTES
-----
This project contains HTML and CSS only, as requested. It has no JavaScript.
The café name, menu, prices, address, hours and contact details are sample content.
Replace them with your real café information before publishing.
